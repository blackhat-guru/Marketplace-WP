    About HTML website templates

    HTML templates are complete, static website front-ends built with HTML, CSS and JavaScript. They load fast, work on any host and are easy to connect to the CMS or backend of your choice.

    On Templora each template lists its pages, components, dependencies and browser support, so you can check it fits your project before you buy. Templates built with Tailwind CSS or Bootstrap are filterable by technology.
